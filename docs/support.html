FAQ

macOS says it can’t verify the app (GitHub download)

Open System Settings → Privacy & Security, scroll down and click Open Anyway. Or run once: xattr -dr com.apple.quarantine /Applications/Coucou.app. The App Store version doesn’t have this step.

Mochi doesn’t show my Claude Code sessions

Open Settings → Claude Code → Install hooks, review the changes, confirm, then start a new Claude Code session.

The chat doesn’t answer

Add your Anthropic API key in Settings. API usage is billed by Anthropic, separately from a Claude subscription.

An integration pill stays grey

Check its key in Settings → Integrations. Up to 4 integrations can be shown at once.

No sound

Check the speaker icon in the notch header and the volume in Settings.

How do I uninstall?

Settings → Claude Code → Uninstall (removes only Coucou’s hooks), then quit the app and move it to the Trash. Optionally delete ~/Library/Application Support/NotchBuddy.

Questions fréquentes

macOS dit qu’il ne peut pas vérifier l’app (téléchargement GitHub)

Réglages Système → Confidentialité et sécurité, en bas : Ouvrir quand même. Ou une fois dans le Terminal : xattr -dr com.apple.quarantine /Applications/Coucou.app. La version App Store n’a pas cette étape.

Mochi n’affiche pas mes sessions Claude Code

Réglages → Claude Code → Install hooks, vérifie les changements, confirme, puis lance une nouvelle session Claude Code.

Le chat ne répond pas

Ajoute ta clé d’API Anthropic dans les Réglages. L’API est facturée par Anthropic, à part d’un abonnement Claude.

Une pastille d’intégration reste grise

Vérifie sa clé dans Réglages → Intégrations. Jusqu’à 4 intégrations s’affichent en même temps.

Pas de son

Vérifie l’icône haut-parleur dans l’en-tête du notch et le volume dans les Réglages.

Comment désinstaller ?

Réglages → Claude Code → Uninstall (retire seulement les hooks de Coucou), puis quitte l’app et mets-la à la corbeille. Tu peux aussi supprimer ~/Library/Application Support/NotchBuddy.
